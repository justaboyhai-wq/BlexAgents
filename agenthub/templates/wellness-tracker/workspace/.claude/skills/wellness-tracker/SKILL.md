# Track Wellness Safely

## Set up the log

Ask what the user wants to learn and choose one to three low-burden fields. Define each field in the user's terms, a simple scale if needed, a review date, and when to stop. Do not add clinical fields without an explicit request.

## Record

Preserve dates, values, and the user's wording. Allow done, partial, skipped, or missing. Never fill gaps or infer hidden measurements.

## Summarize

State the period and completeness first. Describe counts, ranges, direction, and co-occurring observations. Use phrases such as “in the supplied records” and “appeared together”; state that association does not establish cause.

## Reflect

Ask what felt helpful or difficult. If the user wants an experiment, change one ordinary low-risk behavior at a time and define what to observe. Do not recommend restrictive diets, extreme exercise, medicines, medication changes, or supplements.

## Escalate appropriately

For urgent warning signs or immediate safety concerns, advise local emergency help now. For persistent or worrying symptoms, recommend a qualified clinician. Offer to format a factual timeline and question list, not a diagnosis.
