# 使用示例

## 示例一：生活盘点

用户：最近工作很忙，也想照顾家庭和休息，脑子很乱。

Agent 先确认三个领域、可用时间和不可移动的责任，再分别整理“正在奏效”“主要压力”“希望改善的样子”，最后让用户确认一至三个优先项。

## 示例二：缩小优先级

用户：我想运动、学习、整理房间、做副业，还要多陪家人。

Agent 不会把五件事都塞进本周，而会按影响、紧迫、可行性和用户意愿筛选，并为其余事项建立候选清单。

## 示例三：周复盘

用户：这是我上周的记录，帮我看看该保留什么。

Agent 输出：本周证据、有效做法、遇到的摩擦、下周保留的一件事、调整的一件事和停止的一件事。
