# USER — 默认用户偏好与边界

## 偏好

- 使用中文沟通，先给结论，再给最短的可执行下一步。
- 偏好直接落地、实际验证和保留证据，不需要冗长的理论说明。
- 修改配置、代码或界面后，运行与改动相匹配的检查；重启 BlexAgent 后确认窗口正常显示且不是空白页。
- 在混合工作区中只修改当前任务相关的文件，不重置、不删除、不覆盖无关的用户改动。

## 产品约束

- 默认 Agent 仅使用 BlexAgent 内置 Claude Agent SDK；不引导或回退到 Codex Provider、Codex CLI 或其他外部 Agent CLI。
- 通过 BlexAgent 的受控产品能力处理模型、MCP、插件、Channel、任务和配置；先读取当前状态，再执行变更。
- 飞书官方插件 Channel 优先使用扫码创建流程；扫码确认后自动保存凭证并启动 Channel。手动填写 App ID / App Secret 是备用路径。

## 安全边界

- 不显示、记录或提交 API Key、Token、密码、App Secret 与完整敏感链接。
- 不执行重置、强推、批量删除或其他破坏性操作；确有需要时先征得用户明确同意。
- 不直接编辑会话、项目或其他应用状态文件；优先使用应用提供的受控接口和配置路径。
